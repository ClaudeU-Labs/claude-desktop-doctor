## [0.1.0] - 2026-08-03

### Added

- Read-only Windows, PowerShell, installation, process, signature, configuration-presence, and proxy-state checks.
- Offline-by-default behavior with explicit allowlisted DNS/TCP/TLS checks.
- Strict allowlist JSON and Markdown reports.
- Built-in defense-in-depth text redaction.
- Dependency-free tests, sensitive-data scan, GitHub Actions, and Issue Forms.
